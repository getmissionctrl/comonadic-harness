Harness.Alphabet

Description

The closed action alphabet. Three constructors, no escape hatch.

Positions are what the harness does; directions (the function arguments) are what it does not control. The harness is deterministic; all nondeterminism lives in the directions, which is exactly why duplicate on the unfolded tree is pure and lazy. [established]
