Harness.Interp

Description

The single interpreter over the alphabet. Both run (in IO) and probe (pure, fuel-limited) are instances of it, so the law that they agree is free by construction rather than maintained by inspection across two hand-written case analyses (defect D9, §16.1).

The interpreter emits one Ev per node into a Writer and respects a depth bound. Both are monadic effects, not extra constructors. Reading Ctx here only labels an event; the successor is always k result, never a function of the annotation (invariant 2).
