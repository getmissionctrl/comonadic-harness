Harness.Path

Description

The pure path a run takes under a hypothesis. The tree branches on the oracle and the world, which are not under the harness's control; fix a Hypo (a pure stand-in for both) and the branching collapses to a single path. This module holds that collapse so both analysis (Probe) and the test generators can share exactly one definition of it (no drift).

data Hypo Source #

A pure model of the oracle and the world. As crude or as sharp as you like; the forecast is only ever as good as this. Lives here rather than in Probe because it is the thing that turns the branching tree into a path — the subject of takeWalk.
