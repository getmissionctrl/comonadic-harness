exampleStep :: S -> HarnessF S Source #

A minimal coalgebra fragment: emit the request, and on reply either halt with what the model said or record the (unobserved-until-now) response and carry on. The nondeterminism is entirely in the Either Refusal Response argument — the position Render is fixed. This is the §1 move in one line.

exampleRun :: S -> Either Refusal Response -> S Source #

Drive exampleStep one step with a supplied (pure) reply. No oracle, no IO: the successor is a function of the reply, exactly as §1 requires.

irreversible :: [Turn] -> [String] Source #

The irreversible actions a transcript performed, as a plain list (read it as a multiset). A compaction that changes this has changed behaviour, which is the divergence respectsBehaviour is built to catch.
